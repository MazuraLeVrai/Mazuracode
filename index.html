🎮 Comment utiliser les codes sur Roblox

  1. Ouvre Roblox et lance le jeu Anime Dice.
  2. Attends que le jeu soit complètement chargé.
  3. Ouvre le menu du jeu et clique sur le bouton Codes.
  4. Copie un code ici avec le bouton Copier et colle-le dans la case de texte.
  5. Appuie sur Redeem pour recevoir ta récompense !

Astuce : les codes sont sensibles aux majuscules, tape-les exactement comme affichés.
